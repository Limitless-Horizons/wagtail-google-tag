# Security policy

## Supported versions

Security fixes go into the latest release.

## Reporting a vulnerability

Please don't report security issues in public issues or pull requests.

Report them privately through GitHub instead: on this repository's **Security** tab, choose **Report a vulnerability** ([direct link](https://github.com/Limitless-Horizons/wagtail-google-tag/security/advisories/new)). Only the maintainers can see the report.

We'll reply as soon as we can, work with you on a fix, and credit you in the release notes unless you'd rather not be named.
