# Privacy

The package sends no personal data. Email and phone link events carry only `link_type`, never the address or number. Google's own rules forbid personal data in Google Analytics, so keep it out of your own event parameters too.

- A page's address is sent with its page view. If an address holds something Google shouldn't get, see [Keep secrets out of page addresses](../how-to/keep-secrets-out-of-page-addresses.md).
- A User-ID has rules of its own: see [Set a User-ID](../how-to/set-a-user-id.md).
- What the tag does before and after a visitor's choice is in [Consent](consent.md).
